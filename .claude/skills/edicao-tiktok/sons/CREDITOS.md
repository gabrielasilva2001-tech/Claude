# Créditos da biblioteca de sons

Todos os arquivos são de domínio público (licença **CC0**), baixados do OpenGameArt.org, ou foram gerados por síntese.
Foram escolhidos pelos dados de cada arquivo (duração, volume, nome do pacote), **sem audição** — conferir no vídeo.
Quando ela mandar os sons dela, eles substituem estes com o mesmo nome.
